# xuxuanwu
许玄武的实验平台

## AI 介入流程

- **无 AI**。不生成建议。
- **AI 先介入**。视频就绪后呈现已有的演示反馈，随后解锁反思编辑。
- **AI 后介入**。提交最终稿后，根据片头、片中和片尾的反思正文生成一条改进建议，保存在反思记录中。

最终稿建议默认使用本地规则，页面会标明来源。如需接入 AI 模型，请在启动 Flask 前设置以下环境变量。

- `FINAL_FEEDBACK_API_URL` 完整的兼容 Chat Completions 接口地址，包含 `/chat/completions`。
- `FINAL_FEEDBACK_MODEL` 服务部署的模型名称。
- `FINAL_FEEDBACK_API_KEY` 服务需要鉴权时填写，留在服务端环境中。

接口收到分阶段的最终稿正文。生成失败可以重试，最终稿和提交时间仍保存在平台中。
